# quickboot-setup

## Quick Start
Laden Sie die Datei **„Start_bsp.bat“** herunter und legen Sie diese auf dem **Desktop** ab. 
Im Editor müssen Sie anschließend noch den **Pfad** zum **Theme-Pack** hinterlegen. 

---

## Was bringt Ihnen das? 

Wir haben ein kleines **Skript** geschrieben, um auf den Rechnern nicht alles manuell einstellen zu müssen. So können Sie nach dem Anmelden einfach diese Datei ausführen und alle Einstellungen werden automatisch übernommen.

**Features:**
- Hintergrundbild 
- Farbe
- Lernsax-Einbindung im Explorer
- Explorer-Pfad öffnen

---

## Theme-Pack erstellen

Sie können alle Anpassungen in den **Einstellungen** -> **Personalisierung** vornehmen (solange es die Organisation zulässt).

Öffnen Sie **Einstellungen** -> **Personalisierung** -> **Designs**.
<img width="834" height="268" alt="Screenshot Speichen" src="https://github.com/user-attachments/assets/6ab019e9-1afd-47bf-9379-65a9f9415e55" />


Klicken Sie mit der **rechten Maustaste** auf das neu hinzugefügte Design und wählen Sie **„Design für die Freigabe speichern“** (es wird empfohlen, als Speicherort *„H:\“* zu wählen).
<img width="873" height="316" alt="Screenshot Freigabe Speichern" src="https://github.com/user-attachments/assets/c60b3ffe-da6f-4639-a508-6dce75711796" />

Kopieren Sie die Datei am Speicherort mit einem weiteren **Rechtsklick** als Pfad und fügen Sie diesen in das **Skript** ein.
